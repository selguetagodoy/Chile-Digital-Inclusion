# Methodology

Chile Digital Inclusion is a public research repository for measuring digital exclusion beyond simple network coverage.

The project distinguishes four layers: access, device availability, functional use and territorial inequality.

The public release combines evidence from Censo 2024, CASEN, SUBTEL and Ookla Open Data where quality-of-service indicators are used.

Only public or aggregated observations are released. Missing values remain missing. The repository does not publish the complete Digital Vulnerability Index, proprietary weights, private datasets or commercial models.

Internet access is not treated as equivalent to digital inclusion. A household can report connectivity while remaining functionally constrained by mobile-only access, lack of a computer, affordability, limited skills or poor service quality.
