# Data dictionary

The repository separates statistical units and source layers.

- Censo / Atlas household files use households and territories.
- CASEN files use weighted persons (`N_ponderado`) unless the file name or source note states otherwise.
- SUBTEL access files refer to households; SUBTEL use and skills tables refer to people aged 16 or older.
- Ookla files describe observed network performance.

Key variables include fixed Internet, mobile-only access, no Internet, digital-connectivity deprivation, income poverty, device availability, digital skills, functional online uses and network quality.

Commune-level survey estimates should be read together with `N_ponderado` and treated as exploratory where sample support is limited.

The public repository does not include direct identifiers, person-level microdata, proprietary weighting schemes or the complete Digital Vulnerability Index.
