# Uso diario de Internet por edad — SUBTEL 2025

## Alcance

Esta capa publica la desagregación etaria del uso diario de Internet informada por la XII Encuesta de Acceso y Usos de Internet de SUBTEL. Corresponde a la pregunta Q10 sobre frecuencia de uso de Internet durante los últimos tres meses.

El universo es de personas de 16 años o más. Por ello, este indicador no debe confundirse con acceso pagado del hogar, disponibilidad de Internet fija, cobertura de red ni conectividad comunal.

## Resultados publicados

| Grupo de edad | Usa Internet todos los días |
|---|---:|
| 16–29 | 96,9% |
| 30–44 | 97,0% |
| 45–59 | 90,9% |
| 60+ | 74,4% |

La diferencia observada entre 30–44 años y 60+ es de **22,6 puntos porcentuales**. El corte muestra una diferencia de intensidad de uso que permanece oculta si se observa únicamente la disponibilidad de acceso.

## Regla de publicación

Se transcriben exclusivamente los porcentajes publicados por SUBTEL para la categoría “todos los días”. No se estiman categorías faltantes, no se reconstruyen ponderadores y no se combinan estos porcentajes con indicadores de hogares.

El archivo canónico es `data/subtel_longitudinal/subtel_internet_use_by_age_2025.csv`. El script `scripts/build_subtel_internet_use_by_age_2025.py` reproduce de manera determinística la tabla a partir de los valores publicados.
